# CodaVybes V13.3 — Discover + Profile Identity

## What changed
- Discover people are now rendered as a compact responsive list, not large profile cards.
- Tapping a person's avatar/name opens a premium animated profile preview sheet.
- Meet remains available directly from every list row and inside the preview.
- Active CodaVybes+ members receive a black/gold star mark next to the blue verification mark.
- The CodaVybes+ public lookup exposes only an active/not-active boolean; payment, source, dates and wallet data remain private.
- The user's own Profile hero morphs into a compact sticky identity bar after the hero scrolls away and returns to the full hero when scrolled back to the top.
- Real avatar URLs now render through the shared Avatar component when available.
- Discover loading placeholders now match the list layout.
